    ACCESS & PROGRESS

    通行证与解锁规则

    通行证代表已经验证的能力和对应权限。每项资格都有明确的获得条件、审核责任和使用范围；涉及真机、项目或助教的权限，必须经负责人审核后生效。

    当前版本先保存个人资料、任务进度和证据。高级通行证将在人工审核流程接入后逐步开放，页面中的“完成任务”不等于自动获得真机或项目权限。
    入门

    学习与提交

    公开学习
    所有基础课程免登录开放，无需签署协议。
    正式提交
    登录后完成实名协议签署，系统自动归档，无需人工审核协议。
    权限范围
    本机学习记录不授予内部资料、真机或项目权限。
    基础

    Nanodegree Foundation 通行证

    获得条件
    完成规定基础关卡，并提交合格的出村证据包。
    审核方式
    AI 初评，助教或老师终审；退回后可按意见重交。
    解锁范围
    方向任务、进阶教程和项目组申请。
    开发

    工具通行证

    获得条件
    完成 Linux、Git、VS Code 和基础开发任务。
    审核方式
    自动检查与人工抽查结合。
    解锁范围
    基础开发任务和协作仓库练习。
    仿真

    ROS2 通行证

    获得条件
    完成节点、话题、服务和基础仿真任务。
    审核方式
    检查运行结果、日志和代码说明。
    解锁范围
    ROS2 仿真任务和进阶教程。
    导航

    仿真导航通行证

    获得条件
    完成地图、定位、规划和导航证据包。
    审核方式
    方向助教或老师按任务场景审核。
    解锁范围
    SLAM、Nav2 及导航方向任务。
    安全

    真机安全通行证

    获得条件
    完成安全培训、设备操作练习和现场考核。
    审核方式
    设备负责人现场确认，并定期复核。
    解锁范围
    仅在获批设备和场地范围内预约、操作真机。
    项目

    项目成员通行证

    获得条件
    达到方向要求，并通过项目面谈或任务考核。
    审核方式
    项目负责人按职责和保密要求审批。
    解锁范围
    加入对应项目组并访问获批项目任务。
    协作

    助教通行证

    获得条件
    完成指定方向并通过评分一致性与规范培训。
    审核方式
    老师授权、限定审核范围，并定期抽查质量。
    解锁范围
    审核被授权级别的任务，不替代老师终审。

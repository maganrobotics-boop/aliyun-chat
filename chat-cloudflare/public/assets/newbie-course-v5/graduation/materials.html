# 第 7 关：把学习过程交付给另一个人复现

建议 45–60 分钟。前置：前六关的真实成果与记录。本关不是再上传一堆截图，而是把“目标、改动、结果、解释、文件”对应起来。

## 1. 下载证据整理材料

[在线查看完整材料](materials.html) · [虚构样例清单](sample/manifest.json) · [个人清单模板](manifest.template.json) · [检查与打包程序](audit_evidence.py) · [提交单](submission.md)

sample 目录仅含教学用虚构说明，字段 is_demo 为 true，不是实际学生完成课程的证据。你自己的成果放在单独的 my-evidence 文件夹中。

## 2. 跟着样例整理一次

在材料目录运行：

```text
python audit_evidence.py sample/manifest.json
python audit_evidence.py sample/manifest.json --pack demo-evidence.zip
```

应看到 `DEMO_ONLY 示例结构通过，不可作为个人作业`，并统计 6 个关卡、6 个样例文件。压缩包包含清单、文件与 SHA256SUMS.txt。哈希用于核对文件是否被改变，不能证明作者身份、真实运行或内容正确。

逐项观察 manifest：id 对应关卡，command 是实际运行命令或登记操作，expected 是事先预测，actual 是实际结果，change 是你做的改动，explanation 是你对结果的解释，files 是能支撑结论的本地文件路径。

## 3. 修改成自己的证据清单

新建 my-evidence，把 manifest.template.json 复制进去并重命名为 manifest.json，按关卡建立文件夹，把自己实际完成的代码、日志、结果与说明复制进去。

把 is_demo 设置为 false；逐项填写前六关的真实状态与证据。files 使用相对路径，例如 `python/exercise.py` 和 `python/result.txt`。每关至少一个非空证据文件，实际验收仍以该关的提交要求为准。

模板中的 status 默认为 in_progress。只有真正达到该关验收标准时才改为 completed。ROS2 只有离线预检时，应保留进行中并写出阻塞原因；程序会拒绝生成“已齐全”的提交包。不要用改状态来掩盖未完成工作。

填写反思 reflection、下一步 next_goal、助教/AI 帮助 ai_help；未使用可写“未使用”。保留个人思考和真实排错记录，使用参考代码也应说明。

```text
python audit_evidence.py my-evidence/manifest.json
python audit_evidence.py my-evidence/manifest.json --pack my-evidence-v1.zip
```

打包不会覆盖同名文件；修改后用新版本名，例如 v2。超 25 MB 的单个视频可保存到获准的共享位置，再把链接、访问权限和说明写进证据文本。不要把令牌、密码、私人信息或未经授权的项目资料装入包。

变化任务：暂时把一个证据文件改名，运行检查，确认它准确报告缺失；恢复文件名后再检查。保存这次失败与修复的记录，证明你理解清单与文件的对应关系。

## 4. 对照验收标准

| 维度 | 通过标准 |
| --- | --- |
| 完整性 | 前六关各有状态、命令/操作、预期、实际、改动、解释和证据 |
| 可复现性 | 他人能用 README 中的环境和命令找到并复现关键结果 |
| 正确性 | 结果符合各关标准，真实仿真与理论样例明确区分 |
| 可解释性 | 能解释至少一次失败、定位依据和修复后的变化 |
| 可追溯性 | 证据路径可打开，代码版本和助教帮助有记录 |

结构检查只做字段、路径和文件存在性检查；它不会自动批改报告，不会确认文件内容是本人完成，也不会自动授予真机或项目权限。

## 5. 提交证据与下一阶段计划

填写 submission.md，附证据包、检查结果、一页反思和下一阶段计划。做一次 3 分钟演示：30 秒介绍目标，90 秒展示一项修改前后结果，60 秒解释一次失败和下一步。

返回第 7 关，把证据包的授权访问链接与内容摘要填入证据栏。免登录模式仅记录在当前浏览器；正式提交需登录。下载打包程序不会自动上传文件，保存本机进度也不等于教师验收通过。

## 常见问题与助教提示

- 文件缺失：manifest 中的路径相对于 manifest 所在目录，不是电脑桌面或程序所在目录。
- 结构通过但导师打不开链接：检查共享权限与有效期，请导师使用其获授权的账号实际打开链接核对，不为方便验收把非公开资料改成公开访问。
- 还有一关没完成：先记录阻塞和下一步，不要把示例充当成果；可继续整理其他关证据。
- 问助教：“请依据这个清单指出缺失证据，不要把未完成关卡改为通过，也不要替我编造实验结果。”

audit_evidence.py

"""Check a local manifest and package only its explicitly listed relative files."""
import argparse
import hashlib
import json
import sys
import zipfile
from pathlib import Path

STAGES = {"registration", "toolkit", "git-basics", "python-basics", "ros2-simulation", "mini-project"}


def audit(manifest_path):
    root = manifest_path.resolve().parent
    data = json.loads(manifest_path.read_text(encoding="utf-8-sig"))
    errors, files = [], {}
    def filled(text):
        return isinstance(text, str) and bool(text.strip()) and "待填写" not in text
    if not isinstance(data, dict):
        return {}, ["manifest 必须是对象"], {}
    for key in ("learner", "reflection", "next_goal", "ai_help"):
        if not filled(data.get(key)):
            errors.append(key + " 未填写")
    if type(data.get("is_demo")) is not bool:
        errors.append("is_demo 必须是 true 或 false")
    stages = data.get("stages", [])
    if not isinstance(stages, list) or not all(isinstance(s, dict) for s in stages):
        return data, errors + ["stages 应为对象列表"], files
    ids = [s.get("id") for s in stages]
    if len(ids) != 6 or set(ids) != STAGES:
        errors.append("必须逐项列出前六关且不重复")
    for stage in stages:
        name = str(stage.get("id"))
        if stage.get("status") != "completed":
            errors.append(name + " 尚未完成；不能用模板或离线预检代替真实实验")
        for key in ("command", "expected", "actual", "change", "explanation"):
            if not filled(stage.get(key)):
                errors.append(name + ": " + key + " 未填写")
        paths = stage.get("files")
        if not isinstance(paths, list) or not paths:
            errors.append(name + " 缺少证据文件")
            continue
        for value in paths:
            if not isinstance(value, str) or not value:
                errors.append(name + " 文件路径无效")
                continue
            path = root / value
            if Path(value).is_absolute() or ".." in Path(value).parts or "\\" in value or not path.resolve().is_relative_to(root):
                errors.append(name + " 只接受证据目录内的相对路径")
            elif not path.is_file() or path.stat().st_size == 0:
                errors.append(name + " 文件缺失或为空：" + value)
            elif path.stat().st_size > 25*1024*1024:
                errors.append(name + " 单文件超过 25 MB，请用已授权的演示链接写入说明文件")
            else:
                files[value] = hashlib.sha256(path.read_bytes()).hexdigest()
    return data, errors, files


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("manifest")
    parser.add_argument("--pack", metavar="OUTPUT_ZIP")
    args = parser.parse_args()
    try:
        manifest = Path(args.manifest)
        data, errors, files = audit(manifest)
        if errors:
            print("\n".join(errors))
            raise SystemExit(1)
        label = "DEMO_ONLY 示例结构通过，不可作为个人作业" if data["is_demo"] else "证据结构检查通过，等待内容验收"
        print(label)
        print("关卡：6；证据文件：", len(files))
        if args.pack:
            output = Path(args.pack).resolve()
            if output == manifest.resolve() or any(output == (manifest.resolve().parent / p).resolve() for p in files):
                raise ValueError("输出文件不能覆盖输入证据")
            with zipfile.ZipFile(output, "x", compression=zipfile.ZIP_DEFLATED) as bundle:
                packed = json.loads(json.dumps(data))
                for stage in packed["stages"]:
                    stage["files"] = ["evidence/"+p for p in stage["files"]]
                bundle.writestr("manifest.json", json.dumps(packed, ensure_ascii=False, indent=2))
                bundle.writestr("SHA256SUMS.txt", "\n".join(h+"  evidence/"+p for p, h in files.items()))
                for path in files:
                    bundle.write(manifest.resolve().parent/path, "evidence/"+path)
            print("已生成：", output.name)
    except (OSError, ValueError, KeyError, TypeError) as error:
        print("无法整理：", error)
        sys.exit(2)

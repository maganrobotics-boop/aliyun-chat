# 第 1 关：把兴趣变成一周能完成的计划

建议 20–30 分钟。无需编程基础，可先用手机阅读、阅读和填写。完成后应能说明“我现在会什么、投入多少时间、下周拿什么结果来证明”。

## 1. 在线材料

[在线查看完整材料](materials.html) · [虚构示例](profile.example.json) · [个人模板](profile.template.json) · [可选检查程序](check_profile.py) · [提交单](submission.md)

本课教程及全部材料均可在线阅读。JSON 可用文本编辑器打开；尚未安装 Python 时按下方人工清单核对，完成第 2 关后再运行可选检查。不要因环境没装好卡在登记关。

## 2. 跟着示例做一次

示例同学是虚构的机械工程大二学生，每周可用 4 小时。他把 2 小时分配给环境和 Git，2 小时分配给 Python，证据分别是版本输出、提交记录和分析结果。计划总量 4 小时，没有超过可用时间。

先回答：如果环境安装用了 3 小时，Python 任务还适合原样安排吗？应缩小本周任务或调整时间，而不是填一个不可能完成的计划。

如果电脑已有 Python，可在材料目录中运行：

```text
python check_profile.py profile.example.json
```

标准输出：`资料结构检查通过；方向匹配仍需本人和导师讨论。` 这不是实名认证、注册成功或项目录取通知。

## 3. 修改自己的资料

零基础同学可先填写 planning-sheet.md，不需要编辑 JSON。希望练习数据格式时，再复制 profile.template.json，另存为 profile.json。填写昵称、专业、年级、当前基础、学习目标和需要的帮助。不要填写身份证号、家庭地址或账号密码；课程证据不需要这些信息。正式身份与联系方式在系统个人主页中按实际需要填写，不放进公开仓库。

方向代码：`perception` 感知、`navigation` 导航、`control` 控制、`mechanics` 机械、`embedded` 嵌入式、`ai` AI 应用、`undecided` 待选择。这里是学习意向，不自动分配项目；系统个人主页没有对应选项时，在简介补充即可。

- `weekly_hours` 写你实际能稳定安排的时间。
- `week_plan` 每项同时写任务、小时数和具体证据；总时长不得超过可用时间。
- `goal` 写可观察结果，例如“能解释并复现 10 m 路程的计算”，不要只写“学会 Python”。
- `skills` 可以写“零基础”，无需虚报；`help_needed` 写当前最大的一个障碍。

独立变化任务：先拟一个 8 小时计划，再缩减到 4 小时。指出保留哪项、推迟哪项，以及依据。保留修改前后两个版本，解释取舍。

## 4. 对照标准核对

| 验收项 | 通过标准 | 不通过的例子 |
| --- | --- | --- |
| 信息 | 模板无“待填写”，基础描述真实 | 全写“熟练”，无具体经历 |
| 时间 | 每项可执行，总量不超过可用时间 | 可用 4 小时却安排 8 小时 |
| 目标 | 有任务、输出和判断标准 | “努力学习机器人” |
| 调整 | 能解释 8 小时到 4 小时的取舍 | 只把数字改小，任务完全不变 |

可选运行 `python check_profile.py profile.json`。程序仅检查字段和时间，目标是否合理仍要对照清单自评。你也可以把计划表直接写在提交单中，按同一标准验收。

## 5. 提交证据

填写 submission.md：个人计划、调整前后对照、一个具体问题和下周交付。返回第 1 关，把证据链接或摘要粘贴进证据栏。免登录时只保存本机；正式提交需登录。文件仍应保留在自己的学习目录中。

本关不以签署保密协议或等待审批作为公开课程阅读的前提。

## 常见问题与助教提示

- JSON 报错：检查英文双引号和逗号，最后一个字段后不加逗号。也可先用提交单完成内容。
- 不知道选什么方向：先选待选择，做完 Python 和小项目后再比较兴趣，不必现在决定整个毕业课题。
- 问助教：“我每周只有 4 小时，下面两项任务哪项应缩小？请根据验收结果而不是兴趣标签给建议。”

check_profile.py

"""Optional local structure check; does not verify identity or enroll a member."""
import json
import math
import sys
from pathlib import Path


def filled(value):
    return isinstance(value, str) and bool(value.strip()) and "待填写" not in value


def hours(value):
    return type(value) in (int, float) and math.isfinite(value) and 0 < value <= 40


def validate(data):
    errors = []
    if not isinstance(data, dict):
        return ["资料必须是 JSON 对象"]
    for key in ("display_name", "major", "year", "goal", "help_needed"):
        if not filled(data.get(key)):
            errors.append(key + " 未填写（不需要帮助可写‘暂不需要’）")
    if data.get("direction") not in ("undecided", "perception", "navigation", "control", "mechanics", "embedded", "ai"):
        errors.append("direction 必须使用教程中的方向代码")
    skills = data.get("skills")
    if not isinstance(skills, list) or not skills or not all(filled(x) for x in skills):
        errors.append("skills 至少写一项当前基础，也可写‘零基础’")
    if not hours(data.get("weekly_hours")):
        errors.append("weekly_hours 应为 0–40 之间的正数；按自己的实际可用时间填写")
    plans = data.get("week_plan")
    if not isinstance(plans, list) or not plans:
        errors.append("week_plan 至少安排一项任务")
    else:
        valid = all(isinstance(p, dict) and filled(p.get("task")) and filled(p.get("evidence")) and hours(p.get("hours")) for p in plans)
        if not valid:
            errors.append("每项计划需有 task、正数 hours 和具体 evidence")
        elif hours(data.get("weekly_hours")) and sum(p["hours"] for p in plans) > data["weekly_hours"]:
            errors.append("计划总时长超过每周可投入时间")
    return errors


if __name__ == "__main__":
    try:
        data = json.loads(Path(sys.argv[1] if len(sys.argv) > 1 else "profile.json").read_text(encoding="utf-8-sig"))
        errors = validate(data)
        print("\n".join(errors) if errors else "资料结构检查通过；方向匹配仍需本人和导师讨论。")
        sys.exit(bool(errors))
    except (OSError, ValueError) as error:
        print("无法检查：", error)
        sys.exit(2)

# AI 助教 · 教师试卷批改权限修正

用户要求：名称使用「AI 助教」；试卷批改仅在 `@sztu.edu.cn` 教师邮箱登录后的「我的」中显示。

- 去掉 Chat 顶栏和旧课程助教区的公开批改入口；「我的」每次打开时向服务端查询批改权限，成功且有权限后才显示「试卷批改」。
- 教师身份必须来自有效的校内邮箱会话：`visitor_sessions` 中现有 `staff` 角色且邮箱域名恰好为 `sztu.edu.cn`。学生子域、其他域、伪装后缀域和过期会话均不允许。管理员会话不再作为批改权限的后备来源。
- 服务端同时限制提取和批改接口。未登录返回 401，已登录但无权限返回 403；未授权的状态查询不提供模型、解析能力信息。
- 直接打开批改网址时，未授权用户只见教师登录说明，批改表单默认隐藏且禁用。移除该页管理员登录入口，教师登录前校验邮箱后缀；服务器仍为最终权限依据。
- Chat 页面标题、界面品牌和批改页统一为「AI 助教」。保留现有个性化、设置和退出登录功能。

验证：253 项代码检查通过，其中 17 项批改测试；生产代码副本中的 17 项测试通过。桌面 1280×900、手机 390×844、360×780 的浏览器检查通过，覆盖教师菜单、学生隐藏、直接访问受限、批改与导出。
